Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills

paper Hugging Face Papers·1 Sep ·533 upvotes

The most-upvoted paper of the fortnight by a wide margin. It names the gap between an agent's model and its harness as operational knowledge — the know-how that separates knowing a method from making it work — and argues that knowledge already exists in repositories and papers, just in forms written for human readers.

The bottleneckThe paper names the gap directly: operational knowledge — the know-how separating knowing a method from making it work — sits outside the agent entirely. It exists in repositories and papers, but written for human readers, so an agent with a capable backbone and a good harness still cannot reach it.

Why it mattersIt reframes agent failure as a missing knowledge layer rather than a missing capability, which points at a fix that does not require a bigger model.

The trendHarnessDev (259 upvotes, 31 Aug) asks whether agents can evolve their own harness. Both of the fortnight's top papers are about the scaffolding, not the model.

Compile by Training: Turning Natural-Language Specifications into Local Neural Functions

paper Hugging Face Papers·2 Sep ·377 upvotes

Compiles a natural-language spec into a reusable neural function: teacher models generate task-specific examples at compile time to train a small adapter, and the result runs without the teachers. The function can be stored and versioned like code.

The bottleneckRecurring text tasks are easy to describe and hard to write rules for, so they get a frontier-model call per input — paying cost, latency, and provider dependency every time, forever. Compiling the spec into a small adapter at training time removes the teacher from the runtime path entirely.

Why it mattersThe resulting function can be stored and versioned like code, which makes it something an ops team can reason about rather than a per-call bill.

The trendPaired with Qwen 3.8 running at 1,500 tokens/second below, two unrelated attacks on inference cost landed in the same fortnight.
